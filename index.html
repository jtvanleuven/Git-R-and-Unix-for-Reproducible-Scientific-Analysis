Prompt Writing Best Practices AI

You'll use AI throughout this workshop to understand commands, debug errors, and write code. These five rules will make your prompts much more effective:

  1. Give context. Tell the AI what language/tool you're using and what your goal is. "I'm using bash on macOS and I want to…"
  2. Be specific. Vague questions get vague answers. Describe exactly what you have and what you want.
  3. Paste errors verbatim. Copy the full error message — don't paraphrase it. The exact wording matters.
  4. Ask for explanations. Don't just ask for code — ask the AI to explain what each part does so you learn from it.
  5. Iterate in the same conversation. AI remembers context within a session. Follow up, ask "why?", and refine.
